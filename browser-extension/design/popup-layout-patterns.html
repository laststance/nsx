レイアウトと書体 30 パターン

下の 6 点は 全パターンに反映済みです。違いは「左上のメッセージ枠をどう使うか」「保存と投稿をどう並べるか」「書体」の 3 つ。モックは実際に操作できます（チェックで Success が左上にフェードイン → フェードアウト）。 番号で選んでください。レイアウト（01–20・29–30）× 書体（21–28）の組み合わせも可で、上のバーの「書体」を切り替えると全レイアウトにその書体が当たります。

  1. PAT は Options ページへ。ポップアップから緑ドットと接続バーを撤去（未接続のときだけ左上に案内）。
  2. Tweet ボタンは X の黒。#0f1419・15px Bold・36px ピル、hover #272c30。
  3. チェックボックスは 16–20px。見た目だけ小さくし、当たり判定は 40px を維持。
  4. メッセージは左上・12px 前後・緑。Success はフェードイン → 保持 → フェードアウト、Already Exists は表示し続ける。
  5. ボタンを右端に揃える。空のままだった 172px の結果欄をなくし、チェックボックスと右端を通す。
  6. 書体に階層をつける。タイトル / 本文 / メタの 3 段階、和文はプロポーショナル詰め（palt）。

NSX connection

Not connected

Generate a token at nsx.malloc.tokyo → Dashboard → Settings → Extension token. It is shown once; paste it here.

  • 開き方は 3 通り：ツールバーのアイコンを右クリック → 「オプション」／ポップアップ左上の「Open options」／chrome://extensions → 詳細 → 拡張機能のオプション。
  • 実装：WXT の entrypoints/options/ を追加し、今の usePersonalAccessToken をそのまま使う。ポップアップ側は chrome.runtime.openOptionsPage() を呼ぶリンクだけになる。
  • 消えるもの：ステータスドット、折りたたみバー、useConnectionBar、貼り付けパネル。ポップアップを開いた瞬間のフォーカスリングもなくなる。
  • 注意：拡張機能の ID が変わらない限り、保存済みトークンはそのまま使える（chrome.storage.local は popup と options で共有）。
